# FolkOps Transport Route Planner

## Project Activity 3 – Social Coding

FolkOps is a team project that enhances the Cisco Networking Academy
MapQuest Directions REST API application from Lab 4.9.2.

The enhanced application provides a web-based route planning interface
with transport and shipment cost metrics.

## Current Features

- MapQuest Directions API integration
- Origin and destination route planning
- Travel-time calculation
- Distance in miles and kilometers
- Turn-by-turn directions
- Fuel requirement estimation
- Estimated fuel cost
- Cargo weight input
- Total trip cost input
- Transport cost per ton
- Transport cost per kilogram
- Fuel cost percentage
- Input validation
- MapQuest/API error handling
- Responsive web interface

## Technology

- Python
- Flask
- Requests
- HTML
- CSS
- MapQuest Directions API

## Security

The MapQuest API key is stored locally in an environment file and
is excluded from Git using `.gitignore`.
